`DS-02_screens.md`(16화면)·구 `DS-00_overview.md`·구 `DS-01_design_system.md` 는 **폐기**했다. 남아 있다면 무시한다. USS 화면의 시각 근거는 **`01 §4~§7`** 이다.

## 충돌 시 우선순위 (위가 이긴다)

1. **명시적 결정** — `.claude/rules/decisions.md`(D1~D12 + 기타 확정값)
2. **해당 영역의 관할 문서**(위 표)
3. 그 외 문서
4. **코드 ↔ spec 충돌** → 항상 spec 우선
5. **폐기 문서의 잔재 ↔ USS 문서** → 무조건 USS 문서
